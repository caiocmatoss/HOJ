# Regras do Projeto

## Objetivo
Este arquivo define como a IA deve trabalhar neste projeto.

## Regras gerais
- Antes de alterar código, analisar a estrutura existente.
- Não apagar funcionalidades sem autorização.
- Explicar alterações importantes.
- Priorizar código limpo e organizado.

## Arquitetura
- Manter separação entre interface, lógica e dados.
- Evitar código duplicado.

## Segurança
- Nunca colocar senhas ou chaves diretamente no código.
- Validar dados recebidos pelo usuário.

## Desenvolvimento
Antes de implementar uma funcionalidade:
1. Explicar o plano.
2. Listar arquivos que serão alterados.
3. Implementar.
4. Verificar possíveis erros.
